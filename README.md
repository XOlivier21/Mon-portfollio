# Mon Portfolio

Prototype de portfolio créé pour le TP "Votre Portfolio".

Structure:
- `index.html` : page principale
- `css/styles.css` : styles principaux
- `js/script.js` : petit script pour le menu mobile et année
- `assets/avatar.svg` : image d'avatar

Pour tester localement :
- Ouvrir `index.html` dans un navigateur. Pour un serveur local simple :
  - Avec Python 3 : `python -m http.server 8000`

Points pris en compte :
- HTML5, CSS3
- Responsive via media queries
- Navigation, header/footer, sections demandées

Prochaines étapes : améliorer la maquette visuelle, ajouter contenu et projets, accessibilité et petites animations.
